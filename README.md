## About

I work at the intersection of **offensive security** and **applied AI**. My focus is on designing systems that automate the repetitive parts of security research, such as reconnaissance, triage, and reporting, so that more time goes toward analysis and remediation.

- Designing AI-assisted pipelines for vulnerability discovery, proof-of-concept development, and threat reporting
- Participating in bug bounty programs on HackerOne across web application, API, and cloud attack surfaces
- Conducting authorized penetration testing with emphasis on access control (IDOR), SSRF, SSTI, XXE, race conditions, and business logic flaws
- Researching open-source intelligence (OSINT) and geospatial intelligence (GEOINT)

All security testing is performed within authorized scope and follows responsible disclosure practices.

## Approach

- **Offense informs defense.** Understanding how systems fail is the most reliable way to secure them.
- **Automate the repeatable.** If a task is done twice manually, it becomes a tool.
- **Document everything.** Findings are only valuable when they are reproducible and clearly communicated.
